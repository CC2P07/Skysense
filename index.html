01 / SOBRE O PROJETO

Conheça o SkySense.

O SkySense é um projeto acadêmico de estação meteorológica baseada na ESP32. A proposta é coletar dados do ambiente e facilitar a consulta pelo navegador, aproximando o que estudamos de uma aplicação prática.

01

Coletar

Os sensores conectados à ESP32 fazem as leituras das condições ambientais.

02

Transmitir

A conexão permite disponibilizar os dados da estação para consulta.

03

Acompanhar

O dashboard organiza as leituras em indicadores, gráfico e histórico da sessão.

ESP32 / CONEXÃO

Conectar a estação

Informe o endereço que disponibiliza as leituras da sua ESP32.

Para um endereço local por HTTP, use o projeto na mesma rede da ESP32. Na versão HTTPS, conecte uma API HTTPS.

Formato dos dados

A resposta deve ser um objeto JSON. Campos sem leitura podem vir como null . 

{
  "temperatura": 24.5,
  "umidade": 62,
  "pressao": 1013.2,
  "qualidade_ar": 1380,
  "luminosidade": 2100,
  "chuva": false,
  "timestamp": "2026-10-29T12:00:00Z"
}

Pressão em hPa. MQ135 e LDR em ADC de 0 a 4095. Chuva: true ou false . O horário é opcional; sem ele, usamos o momento do recebimento.
